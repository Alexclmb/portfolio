Content repo

Not connected — editing locally only

content.json in your GitHub repo is the single source of truth. This editor loads it on open and writes it back when you publish, so the site and the CMS can't drift apart — and you can edit from any browser or device. Publishing commits content.json only. The v2 site's index.html, js/ and css/ are never touched from here, and the site reads content.json from its own host, so each publish shows up after Netlify's deploy. Use a fine-grained token scoped to this one repo with Contents: Read and write. It's stored only in this browser and is never written into content.json or any export.

Strip

The looping media strip · drag to reorder

Same rules as the site's own check: a picture is in the strip once (look-alikes listed in sameImage count as the same picture), and two neighbours never show the same picture or the same project. The strip loops, so the last tile also sits next to the first. A repeat is refused; a new tile goes into the first gap where it breaks no rule. Anything that breaks a rule is marked red and blocks Publish.
