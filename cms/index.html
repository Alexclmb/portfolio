Content repo

Not connected — editing locally only

content.json in your GitHub repo is the single source of truth. This editor loads it on open and writes it back when you publish, so the site and the CMS can't drift apart — and you can edit from any browser or device. Publishing commits index.html and content.json together in one commit, so your host deploys once. Use a fine-grained token scoped to this one repo with Contents: Read and write. It's stored only in this browser and is never written into content.json or any export.
